## 보안 메모
- 비밀번호 1개 공유 방식이라 **유출 시 누구나 열람·트리아지 가능**. 외부 유출 주의, 주기적 교체 권장.
- `/sync/*`(로컬↔클라우드 동기화)는 별도 `SYNC_TOKEN` 으로 보호(이 게이트와 무관).
- 개인별 식별/감사가 필요해지면 GitHub/Google OAuth 로 승급 가능(코드 구조 동일, auth.ts만 교체).
- 시크릿: `VIEW_PASSWORD`, `SESSION_SECRET`, `SYNC_TOKEN` (모두 wrangler secret).

## 환경값 요약
| 키 | 종류 | 용도 |
|---|---|---|
| `VIEW_PASSWORD` | secret | 열람 비밀번호 |
| `SESSION_SECRET` | secret | 세션 쿠키 서명 |
| `SYNC_TOKEN` | secret | 로컬 동기화기 인증 |
| `DEV_ALLOW_NO_ACCESS` | var | "false"(운영). "true"면 무인증 공개 — 쓰지 말 것 |
