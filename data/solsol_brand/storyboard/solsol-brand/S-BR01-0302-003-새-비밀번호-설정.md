# [S-BR01-0302-003] 새 비밀번호 설정
> route: /password-reset-new · 정리: 나래님 · 최종수정 2026-07-27 (KST) · 상태: 작성완료

> 정책 소스 없음 — `mockup2/src/views/auth/password-reset-new.html`과 `app/pages/password-reset-new.vue`를 직접 대조해 사실 기반으로 작성.

## 기능 정의
- 메일 링크의 `rid`(requestId)·`t`(token) 쿼리로 진입. 두 값 중 하나라도 없으면 폼 대신 "유효하지 않은 재설정 링크입니다" 안내 + 비밀번호 재설정 재요청 링크(`/password-reset`)로 유도.
- 새 비밀번호·새 비밀번호 확인 2필드 입력 → 검증 통과 시 `resetPassword(requestId, token, newPassword)` 호출(BFF `/api/auth/password/reset`) → 성공 시 alert 모달("비밀번호가 재설정되었습니다") → `/login`으로 이동.
- 비밀번호 강도 미터(4단계 바, **장식용** — 통과/실패 판정에는 영향 없음): 8자 이상/대소문자 조합/숫자/특수문자 각 조건 충족 시 1점씩.
- 비밀번호 표시/숨김 토글(눈 아이콘)이 두 필드 각각 독립 동작.

## 표시 조건 · 상태·분기
- `linkMissing`(rid 또는 t 없음) → 폼 자체를 숨기고 에러 문구만 표시.
- 비밀번호 필수: 8~16자, 영문·숫자·특수문자 조합 필수(마크업 표기는 "영문 대소문자"이나, 실제 검증 로직 `/[A-Za-z]/`은 대소문자 구분 없이 영문 포함 여부만 판단 — **실행 코드가 정본**).
- 확인 필드 공란/불일치 시 개별 에러 표시.
- API 오류 시 필드별(`err.field==='password'`) 또는 폼 전체 에러로 분기, brand-api 미도달(`isUnreachable`) 시 `MockBadge` 노출.
