# [S-BR01-1201-010] 구독 취소 안내 메일
> route: 해당 없음(서버 발송 트리거 — brand-api 이벤트) · 정리: 새롬님 · 최종수정 2026-07-27 (KST) · 상태: 작성완료

## 기능 정의
- 사용자가 구독 취소(`/my/product-cancel`)를 완료했을 때 발송되는 HTML 이메일(`my/subscription-cancel-email.html`).
- 구성: 알림 아이콘 + "구독이 취소되었습니다" + "{{USER_NAME}} 님의 구독 취소가 정상적으로 처리되었습니다 / 남은 구독 기간 동안은 계속 서비스를 이용하실 수 있습니다" + 구독 정보(사이트명·구독유형·취소 신청일·서비스 이용 가능일·서비스 상태="이용 가능 (취소 예정)") + 안내(만료일까지 정상이용, 종료 전 재시작 가능, 즉시취소·환불은 1:1 문의) + **[구독 플랜 보기] CTA**(`/pricing`).
- mockup2 `product-cancel-confirm-modal.html`의 목업 한정 로직(`window.open('subscription-cancel-email.html', ...)`)이 바로 이 메일을 새 창으로 미리보기하는 데모 동작이었다 — 실제 스파이크(`product-cancel.vue`)는 이 새 창 오픈을 구현하지 않고 완료 alert만 표시.

## 표시 조건 · 상태·분기
- 트리거: `DELETE /api/subscriptions/:id`(mode=expire) 성공 시.
- `mode='expire'` 정책과 정합 — 즉시 해지가 아니라 만료일까지 계속 이용 가능하다는 문구.

## 정책 (변경 사항 · 값·수치)
- 별도 전용 정책문서 없음 — `S-BR01-0801-003`(구독취소 화면)·`S-BR01-0801-003_pu01`(완료 안내 모달)과 같은 이벤트를 트리거로 공유.
- 즉시취소·환불 절차는 "1:1 문의를 통해 접수"로 안내 — 실제 환불은 수동 처리 정책([[brand-refund-policy-manual]] 참조, 토스 PG 자동취소 미사용)과 일관.

특이사항 없음.
