# [S-BR01-0901-001_pu05] 계정 삭제(탈퇴) 확인(LPU)
> route: /my/account (모달, 부모=S-BR01-0901-001 계정관리) · 정리: 새롬님 · 최종수정 2026-07-27 (KST) · 상태: 작성완료

## 기능 정의
- 계정관리 하단 '계정삭제' 링크 클릭 시 뜨는 대형(`modal-card--lg`) 확인 모달(`account-delete-modal.html`).
- 구성: 경고 아이콘 + "탈퇴하기" 타이틀 + 안내("계정을 삭제하면 모든 데이터가 영구적으로 삭제되며 복구할 수 없습니다. 신중하게 결정해주세요.") + "탈퇴하시겠습니까?" + 주의사항 목록(계정정보·구매내역·콘텐츠 내역 전체 삭제, 탈퇴 후 환불·백업 불가) + **동의 체크박스**("위 내용에 동의 합니다") + **현재 비밀번호 입력란** + 취소/탈퇴하기 버튼.
- mockup2 원본은 **동의 체크 + 비밀번호 입력 두 조건을 모두 만족**해야 탈퇴 진행(로그인 페이지로 이동). 동의 X → "위 내용에 동의해 주세요"(모달 유지). 비번 공란 → "현재 비밀번호를 입력해 주세요"(모달 유지, 포커스 이동).
- 스파이크(`app/pages/my/account.vue:182-190`)는 확인 게이트까지만 구현하고 **실 삭제 호출은 비활성화**돼 있다 — 확인 시 "탈퇴 요청이 확인되었습니다. / 이번 스파이크 빌드는 비가역 삭제를 안전을 위해 비활성화했습니다. 실제 탈퇴 처리는 정식 연동 이후 적용됩니다."라는 alert만 노출(실 `DELETE /api/account` 미호출).

## 표시 조건 · 상태·분기
- 동의 미체크 → 진행 차단(모달 유지, 경고 문구).
- 비밀번호 공란 → 진행 차단(모달 유지, 경고 문구, 비밀번호 필드 포커스).
- 둘 다 만족 → mockup2는 "탈퇴가 완료되었습니다" 후 로그인 페이지로 이동(`data-delete-success="/src/views/auth/login.html"`). 스파이크는 실제 삭제 대신 "탈퇴 요청이 확인되었습니다"(비활성화 안내)만 노출하고 페이지 이동 없음.

## 정책 (변경 사항 · 값·수치)
- `docs/policy/brand/front/account.md` §"계정 탈퇴" 근거 — **오너 확인(탈퇴/비가역)** 표시 유지.
- **오너 확인 필요(비가역)**: 실 `DELETE /api/account`(진짜 비가역 삭제)는 스파이크 단계에서 의도적으로 미호출 상태(`account.vue:20,182-190` 주석 — "실제로는 즉시 삭제(soft-delete)하는 비가역"이라 안전을 위해 비활성화). 정식 연동 시점·비밀번호 실 검증 로직은 오너/보안 확인 후 별도 진행.
