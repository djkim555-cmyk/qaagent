# [S-BR01-0701-001_pu01] 파일 용량초과 안내(LPU)
> route: /inquiry (모달, 부모=S-BR01-0701-001 문의하기) · 정리: 새롬님 · 최종수정 2026-07-27 (KST) · 상태: 작성완료

## 기능 정의
- 문의하기(`/inquiry`) 첨부파일 업로드 중 **파일당 10MB를 초과**하는 파일을 선택하면 뜨는 확인-단독(Alert) 모달.
- 문구: "파일 용량이 업로드 가능한 최대 용량을 초과했습니다." + 확인 버튼 1개(`data-modal-close`). 해당 파일은 목록에 추가되지 않는다.
- mockup2 `inquiry-file-size-modal.html` 원본에는 이 모달이 페이지 하단에 항상 렌더된 `.modal-overlay`로 붙어 있고(정적 데모 특성), 업로드 버튼 클릭이 실제로는 파일 피커를 여는 게 아니라 **무조건 이 모달을 여는 버그**가 있었다(문서 `docs/policy/brand/front/inquiry.md`에 기록된 변경 사항) — 버그는 파일 피커 트리거로 수정 완료.

## 표시 조건 · 상태·분기
- 트리거: 첨부파일 개별 용량 > 10MB.
- 최대 첨부 개수(5개) 초과는 **다른 알림**("첨부파일은 최대 5개까지 등록할 수 있습니다.")이라 이 화면ID와 별개.

## 정책 (변경 사항 · 값·수치)
- 임계값: 파일당 **10MB**, 최대 **5개**, 허용 형식(이미지/PDF/문서/압축).
- 별도 전용 정책문서 없음 — `docs/policy/brand/front/inquiry.md` §"첨부파일(목업)"이 근거.
- 실제 업로드는 스토리지(R2 등) 연동·MIME/용량 서버 검증 필요 — 계약 정본은 brand-api `/doc`.

## 디자인 이슈
특이사항 없음(범용 Alert 단순 확인창, br01-r04 결함표에 이 모달 관련 open 항목 없음).
