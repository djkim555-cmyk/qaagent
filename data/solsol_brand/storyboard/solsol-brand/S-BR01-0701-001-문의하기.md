## 기능 정의
- 첨부파일: '파일 업로드' 버튼 → 파일 선택창 열림. 선택 파일이 `.file-list`에 아이콘+파일명으로 추가, ✕로 삭제.
- 제목 미입력 제출 시 "문의 제목을 입력해 주세요" 표시(인라인 핸들러가 제목 required 포함 검증).

## 표시 조건 · 상태·분기
- 파일당 10MB 초과 → 용량 초과 모달(`inquiry-file-size-modal`, 확인-단독) 표시·해당 파일 미추가.
- 최대 5개, 초과 시 "첨부파일은 최대 5개까지 등록할 수 있습니다." 알림.
- 업로드 버튼이 "무조건 용량초과 모달을 열던 버그"는 해소되어 파일 피커 정상 트리거로 동작.

## 정책 (변경 사항 · 값·수치)
- 첨부파일: 최대 5개 · 파일당 10MB · 허용(이미지/PDF/문서/압축).
- 실제 업로드는 스토리지(R2 등) 연동·MIME/용량 서버 검증 필요 — 계약 정본 = `/doc`.
