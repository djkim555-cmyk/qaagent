## 기능 정의
- 정적 법적 문서 화면. `LegalDocument` 공용 컴포넌트(레이아웃 `bare`)에 슬롯으로 조문 목록을 흘려넣는 구조 — 제목·개정이력 드롭다운은 컴포넌트가, 본문(제1장~제9장 30개 조 + 부칙)은 `terms.vue` 템플릿이 정적 HTML로 직접 보유한다.
- 서버 API 연동 없음(SSR 정적 렌더). 본문 출처: 오너 제공 1차가안 PDF(2026-07-28) — 이전 목업2 `footer/terms.html` 1px 이식 스텁(제1~4조뿐)을 대체했다.

## 표시 조건 · 상태·분기
- 전역 미들웨어(`app/middleware/01.require-auth.global.ts`) 보호 대상(`PROTECTED_EXACT`·`/my/**`)에 `/terms`가 포함되지 않아 **로그인 여부와 무관하게 접근 가능**(공개).
- 장(章) 제목(`legal-list__chapter`)은 이 페이지 전용 scoped 스타일로만 표현 — 공용 `base.css`는 변경하지 않음.
- 개정이력 드롭다운은 리비전 1건뿐이라 정보 표시용(선택해도 상태 변화 없음, `LegalDocument` 공통 동작).

## 정책 (변경 사항 · 값·수치)
- 2026-07-28 오너 1차가안 PDF 전면 개정 — 총 9장 30개 조 + 부칙. **아직 법무/오너 최종 확정 전 단계**.
- 원문 `[ ]` 대괄호 TBD 표기(예: `[7일]`·`[30%]`·`[서울중앙지방법원 또는 회사 소재지 관할법원]` 등)를 임의로 채우지 않고 그대로 유지 — 조문 다수(제3·9·10·11·14~20·22·24·25·27·30조 등)에 잔존.
- 부칙 ①의 "2026년 09월 01일부터 적용"은 초안 목표 시행일일 뿐 확정이 아니므로 `LegalDocument`의 `revision` prop(개정이력 배지, 기본값 `2025.01.01 개정`)에는 반영하지 않았다.
