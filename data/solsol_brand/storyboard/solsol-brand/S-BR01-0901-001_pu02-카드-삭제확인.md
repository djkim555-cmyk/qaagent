# [S-BR01-0901-001_pu02] 카드 삭제 확인(LPU)
> route: /my/account (모달, 부모=S-BR01-0901-001 계정관리) · 정리: 새롬님 · 최종수정 2026-07-27 (KST) · 상태: 작성완료

## 기능 정의
- 결제 수단(카드) 목록에서 '삭제' 버튼 클릭 시 뜨는 확인(Y/N) 모달.
- 문구: "{카드사}(****{끝4자리}) 카드를 삭제하시겠어요?" + 취소/확인 버튼.
- 확인 시 해당 카드가 목록에서 제거된다.
- 스파이크(`app/pages/my/account.vue:81-104`)는 `useModal().confirm(...)` + `DELETE /api/billing/cards/:id` 실 연동으로 재현.

## 표시 조건 · 상태·분기
- **대표 카드는 이 모달로 진입하지 않는다** — 대표 카드 삭제 클릭 시에는 이 확인 모달 대신 안내 모달(`S-BR01-0901-001_pu04` 대표카드 삭제불가 안내)이 뜬다(클라에서 `card.isDefault` 먼저 판별).
- **카드가 1장뿐이면** 이 확인 모달 대신 `S-BR01-0901-001_pu03`(최소 1개 유지 안내)로 분기 — 최소 1장 유지 판정이 대표 카드 삭제불가 판정보다 **우선**한다(카드 1장은 항상 대표이기도 하므로, 문구는 "대표 카드"가 아니라 "최소 1장" 쪽을 노출).

## 정책 (변경 사항 · 값·수치)
- `docs/policy/brand/front/account.md` §"결제 수단(카드)" 근거 — **오너 확인(결제수단)**.
- 분기 우선순위(최소1장 > 대표카드삭제불가 > 일반삭제확인)는 스파이크 주석(`account.vue:79-80`)에 명시된 판단.
