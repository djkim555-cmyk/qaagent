# [S-BR01-0401-001_pu02] 도메인 사용중 안내
> route: MOCK(브리프 표기, 실측 결과 실 API 연동 확인 — 아래 정정 참조) · 정리: 새롬님 · 최종수정 2026-07-27 (KST) · 상태: 작성완료

> 정책 소스(`sites-home-signup.md`)에 도메인 중복확인 모달 관련 직접 서술 없음 — `mockup2/src/views/my/sites-create.html`과 실제 `app/pages/my/sites/create.vue`·`solsol-brand-api/src/routes/sites.ts` 코드를 직접 대조해 작성.

> **[2026-07-27 신규 분리]** 이 화면ID는 매핑표(`docs/validation_modified/BR01_화면ID_매핑표.md` §3.1)가 목업2 파일 `sites-create-domain-taken-modal.html`(사용 중)에 대응해 신규 분리한 것이다 — 기존에는 [`S-BR01-0401-001_pu01`](./S-BR01-0401-001_pu01-도메인-중복확인-모달.md) 파일 하나에 "사용 가능/사용 중" 2개 상태가 함께 서술돼 있었고, `_pu02`가 존재하지 않았다. 이 파일이 "사용 중" 상태를 독립적으로 다루는 신규 파일이다. "사용 가능" 상태는 [`S-BR01-0401-001_pu01`](./S-BR01-0401-001_pu01-도메인-중복확인-모달.md)을 본다. 기능 정의·정책·API 연동 정보 등 두 상태에 공통되는 서술은 각 파일이 독립적으로 읽혀야 하므로 양쪽에 중복 기재했다.

## 기능 정의
- '내 사이트 만들기'(S-BR01-0401-001, `/my/sites/create`) 화면에서 '도메인 중복 체크' 버튼 클릭 시, 입력한 도메인이 **이미 사용 중인 경우** 뜨는 결과 알럿(확인-단독). "사용 가능"한 경우의 결과 알럿은 별도 화면 [`S-BR01-0401-001_pu01`](./S-BR01-0401-001_pu01-도메인-중복확인-모달.md)에서 다룬다.
- **[정정] 위임 브리프에는 "중복확인 EP 부재로 MOCK 상태(계약보류)"로 안내되어 있었으나, 실제 코드 대조 결과 이 기능은 실 API로 연동되어 있음이 확인됨**: `app/pages/my/sites/create.vue`의 `onDomainCheckClick()`이 `GET /api/sites/check-slug?slug=`를 실제로 호출하고, brand-api `solsol-brand-api/src/routes/sites.ts:245-266`에 해당 엔드포인트가 실제 존재·구현되어 있다(마스터 DB `site.slug` 유니크 조회, `available: rows.length===0`이면 사용 가능, 1건 이상이면 사용 중).
- 최종 유일성 판정은 여전히 "생성하기" 제출 시점에 서버가 `ALREADY_EXISTS`로 재확정한다(이 모달은 사용자 편의용 사전 확인, 체크~제출 사이 경쟁 상태 대비 안전망).

## 표시 조건 · 상태·분기
- 도메인 미입력 시 '도메인 중복 체크' 버튼 비활성화.
- **사용 중** → close 아이콘(`/images/i-64-close.svg`) + "이미 사용 중인 도메인입니다" + "다른 도메인을 선택해 주세요 — https://{slug}.solsol.live" desc, 도메인 입력 필드(`domainError`)에도 "이미 사용 중인 도메인입니다." 에러 표시.
- brand-api 미도달 등 오류 시 `unreachable` 처리 + 폼 전체 에러 메시지(이 오류 처리는 사용 가능 상태와 공통).

## 정책 (변경 사항 · 값·수치)
- 도메인 표기 변경: 목업2 `.solsol.com` → 실앱 `.solsol.live`(2026-07-20, 커밋 `71f948d`) — 목업2가 구 표기(`solsol.com`)로 남아있어 **목업2 자체가 stale한 상태**(스파이크 미이식이 아니라 정책 변경이 목업2에 역이관되지 않은 사례, br01-r04 §4 관찰). "사용 중" 결과 모달도 도메인 값을 표시하므로("다른 도메인을 선택해 주세요 — https://{slug}.solsol.live") 이 표기 불일치가 동일하게 해당한다.
- 슬러그 규칙: 소문자 시작, 영소문자/숫자/하이픈, 끝은 영숫자(`SLUG_PATTERN`). **길이 상한 불일치(정정, 2026-07-27 3차 QA)**: 클라(`create.vue:37`)는 3~30자, 서버(`sites.ts:355`)는 3~50자로 다름 — "동일"이 아님(상세는 `S-BR01-0401-001_pu01` 참조).

## 이식 주의 종합
- **중요 정정**: 이 화면은 위임 브리프상 "mock(계약보류)"로 안내됐으나 2026-07-27 시점 코드 실측 결과 실제 API(`check-slug`)로 완전 연동되어 있다. 허브 담당(총괄)에게 이 정정을 보고해 관련 원장 표기 갱신 여부를 확인받을 것.
- 목업2의 구 도메인 표기(`.solsol.com`)는 정책 변경(→`.solsol.live`)이 목업2에 반영되지 않은 것뿐 — 이 화면(스파이크)의 결함이 아니므로 재작업 불필요.
- 최종 유일성은 여전히 생성 제출 시점 서버 재검증이 담당 — 이 모달의 사전 확인 결과와 제출 결과가 다를 수 있음(레이스 컨디션, 설계상 의도된 동작).
- "사용 가능" 상태(체크 아이콘·desc 등)는 이 파일 범위가 아님 — [`S-BR01-0401-001_pu01`](./S-BR01-0401-001_pu01-도메인-중복확인-모달.md) 참조.
