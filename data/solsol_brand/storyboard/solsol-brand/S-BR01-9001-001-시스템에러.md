# [S-BR01-9001-001] 시스템 에러
> route: /error/system-error · 정리: 나래님 · 최종수정 2026-07-27 (KST) · 상태: 작성완료

## 기능 정의
- 서비스 시스템 에러(500계열) 안내 화면. "서비스 이용에 불편을 드려 죄송해요" 타이틀 + "편리하게 서비스를 이용하실 수 있도록 최선의 노력을 다하고 있어요" 안내 + 캐릭터 이미지(`char-part-error.png`) + "홈으로 가기" CTA.
- 실제 500 오류는 전역 에러 핸들러(`app/error.vue`)가 자동 렌더하는 것과 동일 콘텐츠 — 이 라우트(`/error/system-error`)는 디자인 QA·직접 미리보기 용도로 고정 URL을 통해 별도 도달 가능하게 마련된 화면.

## 표시 조건 · 상태·분기
- 고정 콘텐츠 화면(상태 분기 없음). `layout: 'bare'`(공통 헤더/푸터 없이 단독 레이아웃).

## 정책 (변경 사항 · 값·수치)
- **별도 전용 정책문서 없음** — 화면 자체가 단순 안내 화면. `app/pages/error/system-error.vue` 코드 확인.

## 이식 주의 종합
- 이 화면(시스템 에러)과 404 화면의 코드 주석 화면ID가 서로 뒤바뀌어 있다 — 주석만 고치면 되는 하 심각도 결함이나, 개발 착수 전 정정 권장(추적키 검색 시 혼동 방지).
- `app/error.vue`(전역 에러 핸들러)와 이 화면(`/error/system-error`, 직접 접근용)이 동일 콘텐츠를 이중 유지하고 있음 — 문구 변경 시 두 파일을 함께 수정할 것.
