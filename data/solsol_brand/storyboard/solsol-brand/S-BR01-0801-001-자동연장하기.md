# [S-BR01-0801-001] 자동 연장하기
> route: /my/product-auto-renew · 정리: 나래님 · 최종수정 2026-07-27 (KST) · 상태: 작성완료

## 기능 정의
- 만료임박/만료 구독을 연장하는 화면. "선택된 플랜" 요약 카드(플랜명·배지·사이트명·플랫폼 수수료·구독 주기·만료 예정일) + 연장 기간 선택(1/6/12개월 토글) + 결제 예정 금액 + 안내(콘텐츠·학습자 데이터 유지, 기존 플랜 동일 기능) + 결제 카드 선택 + 약관 동의 + 결제 버튼으로 구성.
- 쿼리: `subscriptionId`(필수 — `my/sites.vue`가 기간만료/만료임박 사이트에서 전달).
- 목업2 원본은 "결제하기" 버튼이 곧장 `payment/purchase.html`로 이동하는 정적 링크였지만(연장 전용 컨트롤 없음), 실연동(`POST /api/subscriptions/:id/extend` ⚠️게이트)은 연장 개월수(1/6/12)가 필수 입력이라 개월 선택 토글이 신규 추가됨(목업2 정본 미제공 컨트롤 — 기존 디자인 토큰만 재사용).
- 6개월 10%/12개월 30% 할인은 서버 TODO 주석 기반 `[추정]`이라 `MockBadge`("견적(확정 아님)")로 표기, 실 청구 금액은 결제 승인(스테이징) 시점에 서버가 확정.

## 표시 조건 · 상태·분기
- 로딩/에러/구독 없음(empty, "내 사이트 관리하기"로 유도) 3분기.
- 결제 버튼 비활성 조건: 카드 미선택 또는 약관 미동의.
- 성공 시 `/purchase-complete?subscriptionId=…`, 실패 시 `/purchase-failed?reason=…`.

- **별도 전용 정책문서 없음** — `mockup2/src/views/my/product-auto-renew.html`과 `app/pages/my/product-auto-renew.vue`를 직접 대조해 기능을 서술함.
- 연장 개월수 할인율(6개월 10%/12개월 30%)은 서버 소스(`subscriptions.ts` TODO 주석) 기반 `[추정]` — 결정책임자·기한 `[미확정]`.
- **오너 확인(금전/결제)** — 연장 결제는 금전 영향 항목.
