# [S-BR01-0801-003] 구독 취소
> route: /my/product-cancel · 정리: 나래님 · 최종수정 2026-07-27 (KST) · 상태: 작성완료

## 기능 정의
- 구독 취소 안내 화면. "구독 취소가 아쉬워요!" 타이틀 + 안내(구독 기간 종료일까지 계속 이용 가능·자동 갱신 비활성화·카드 정보 자동 삭제(다른 결제 사용 카드는 유지)·재가입 언제든 가능) + 현재 사이트 구독 정보(현재 플랜·구독 만료 예정일) + "구독 취소하기" 버튼.
- "구독 취소하기" 클릭 시 확인 모달("정말 구독을 취소하시겠어요?") → 확인 시 `DELETE /api/subscriptions/:id`(`mode:'expire'` 고정) 호출 → 성공 시 완료 알림 모달("구독 취소가 완료되었습니다" / "내 사이트 관리하기에서 확인하실 수 있습니다") 노출.
- `mode='expire'` 고정 — "즉시 해지 아님, 기간 만료까지 계속 이용 가능" 정책과 정합.
- 이미 취소 완료된 구독은 empty 안내("이미 해지된 구독이에요"), 이미 취소 예약(만료 대기) 상태는 "구독 취소하기" 버튼을 숨기고 예약 안내 문구만 노출.

## 표시 조건 · 상태·분기
- 쿼리: `subscriptionId`(필수). 로딩/에러/구독 없음(empty)/이미 취소됨(empty)/정상(구독취소 UI) 다분기.
- `alreadyScheduled`(취소 예약됨, 아직 미종료) 상태에서는 취소 버튼 대신 "이미 구독 취소가 예약되어 있어요 — {만료일}까지 계속 이용하실 수 있어요" 문구만 노출.

## 정책 (변경 사항 · 값·수치)
- **별도 전용 정책문서 없음** — `mockup2/src/views/my/product-cancel.html`과 `app/pages/my/product-cancel.vue`를 직접 대조해 기능을 서술함.
- **방침(accepted-risk, 오너 승인 완료 2026-07-16)**: `DELETE /api/subscriptions/:id`는 실 PG 호출이 없는 순수 상태 전이 엔드포인트다(mode=expire → cancel_scheduled=1·잔여기간 유지 / mode=now → 즉시 canceled). `my/account.vue`의 계정삭제(진짜 비가역 삭제)와는 위험도가 다르다고 판단해 실 호출을 활성화(이전 세션의 "실 호출 안 함" 결정을 뒤집는 것 — 무음 성공 위장 금지 원칙상, "완료" 문구를 보여주면서 실제로는 아무 일도 안 하는 쪽이 더 위험하다고 판단). 코드 주석에 근거 명시(`app/pages/my/product-cancel.vue:10-16`).
- 구독 취소 완료 안내: `docs/design/brand/new-screens-spec-0102-0103.md`, `03_brand-site.md` L704~705 SoT 카피 그대로 이식("✕ 빨강 + 구독 취소가 완료되었습니다 + 내 사이트 관리하기에서 확인하실 수 있습니다 + [확인]"). **[주석]** 이 완료 안내는 `S-BR01-0801-001_pu01`이라는 ID로 언급되는 경우가 있으나, 이는 원 SoT(`docs/validation/03_brand-site.md:704`)의 **구 넘버링**에서 유래한 것이다 — 당시엔 0801-001이 "구독취소" 화면이었으나 화면ID 재수확(D03) 이후 0801-001은 "자동연장하기"(`S-BR01-0801-001-자동연장하기.md`)로 재배정되어, 현재 storyboard 체계엔 `S-BR01-0801-001_pu01`에 대응하는 파일이 없다. 이 완료 안내 자체의 정식 추적 ID는 `S-BR01-0801-003_pu01`(본 화면의 자식)이다. `S-BR01-0801-003_pu01`과의 관계·통합 여부는 **오너 확인 대기 중**(매핑표 `docs/validation_modified/BR01_화면ID_매핑표.md` §6.4). **2026-07-27 2차 QA 정책·기획 페르소나 권고**: `S-BR01-0801-001_pu01`은 실제 대응 파일이 없는 죽은 참조이고(0801-001이 이미 "자동연장하기"라는 별개 실체로 재배정됨), 역할을 나눌 대상 자체가 없으므로 **통합(단일 소유권)** — `S-BR01-0801-003_pu01`을 유일 정본으로 확정하고 `03_brand-site.md`엔 각주만 남기는 방안을 권고함(최종 확정은 오너/기획-lead 서명 필요, 상세 근거 = `docs/dev-validation/spike/_storyboard-qa2-policy.md`).

## 이식 주의 종합
- 실 취소 API(`DELETE /api/subscriptions/:id`)는 이미 활성화됨(2026-07-16, 오너 승인) — 재작업 시 이 결정을 뒤집으려면 별도 오너 재승인 필요.
- `mode='expire'` 고정값을 `mode='now'`(즉시 해지)로 바꾸는 UI/정책 변경은 이번 문서 범위 밖 — 필요 시 오너 확인 후 별도 진행.
- 확인 모달 카피·완료 모달 카피는 `03_brand-site.md` SoT를 그대로 따를 것(임의 수정 금지).
