# 통합테스트 시나리오 — 구글 파트너 정산 시스템

> 작성일: 2026-06-01  
> 대상 서비스: 구글 파트너 정산 (시냅스엠 내부 정산 도구)

---

## 1. 서비스 개요

- **서비스명**: 구글 파트너 정산
- **한 줄 설명**: 매월 구글 광고 수익을 파트너사에 비율·기준에 따라 정산하기 위한 내부 관리 도구
- **대상 사용자**: 시냅스엠 정산 담당자 (파트너 계약 관리, 월별 정산 실행, 리포트 확인)
- **핵심 가치 제안**: 파트너 비율 설정 → CSV 업로드 → 자동 계산 → 마감·리포트까지 한 화면에서 처리해 정산 오류를 줄이고 업무 시간을 단축한다

---

## 2. 테스트 환경

- **대상 URL**: http://localhost:8000/
- **접근 방식**: 비밀번호 로그인 필요
- **테스트 계정**: 비밀번호 단일 인증 — `${ENV:QA_TEST_PASSWORD}` (실제값: googleset)
- **지원 뷰포트**: PC(1440×900) 기준 (주요 사용 환경); 모바일(390×844) 반응형 확인 병행

---

## 3. 사전 조건 (Preconditions)

- 브라우저에서 http://localhost:8000/ 에 접속 가능한 상태 (서버 실행 중)
- 이전 테스트 데이터가 없는 새 세션, 또는 로컬스토리지가 초기화된 상태를 권장
  (기존 데이터가 있을 경우 T3~T8 태스크는 그 데이터를 기반으로 진행)
- CSV 업로드 테스트(T6)를 위해 테스트용 광고수익총금액 CSV 및
  서빙피계산 인보이스확인 CSV 파일을 준비하거나, 업로드 UI의 반응만 확인

---

## 4. 테스트 태스크 (사용자 목표 단위)

### T1. 로그인 및 첫인상 확인

- **목표**: 비밀번호를 입력해 시스템에 접근하고, 로그인 후 화면이 올바르게 진입되는지 확인한다
- **시작 지점**: http://localhost:8000/ 초기 화면 (로그인 페이지)
- **성공 기준**:
  - 올바른 비밀번호 입력 시 대시보드(또는 메인 화면)로 전환된다
  - 틀린 비밀번호 입력 시 명확한 오류 메시지가 표시된다
  - 로그인 후 상단 내비게이션(메뉴)이 정상 노출된다
- **관찰 포인트**:
  - 로그인 페이지의 레이아웃·브랜드 표시가 자연스러운가
  - 비밀번호 필드의 마스킹, 엔터키 제출 여부
  - 오류 메시지가 친절하고 명확한가

---

### T2. 대시보드 현황 파악

- **목표**: 로그인 직후 전체 정산 현황(총 계약 건수, 진행 중 정산 건수, 총 예상 금액)을 한눈에 파악한다
- **시작 지점**: 로그인 완료 후 대시보드
- **성공 기준**:
  - 총 정산 계약, 진행 중 정산, 총 예상 금액 수치가 표시된다
  - 각 지표가 어떤 의미인지 레이블이 함께 보인다
- **관찰 포인트**:
  - 수치가 "0건 / ₩0" 인 경우 빈 상태 처리가 적절한가
  - 대시보드에서 세부 메뉴로 바로 이동할 수 있는가

---

### T3. 파트너 정산 비율 등록 및 마감

- **목표**: 이번 달 정산에 적용할 파트너별 수수료율·서빙피 분담 비율·운영 대행 수수료를 입력하고 저장·마감한다
- **시작 지점**: 상단 내비게이션 → 파트너 정산 비율
- **성공 기준**:
  - 파트너를 1명 이상 추가하고 수수료 비율(%)을 입력·저장할 수 있다
  - 저장 후 "저장되었습니다" 류의 피드백이 표시된다
  - 적용 년월을 변경해도 기존 데이터가 유지되거나 "이전 달 기준이 적용됩니다" 안내가 정확히 뜬다
  - 마감 토글을 활성화하면 모든 입력 필드가 잠기고 "마감" 배지가 표시된다
  - 마감 상태에서 저장 버튼이 비활성화된다
- **관찰 포인트**:
  - 파트너 삭제 시 운영 대행 수수료 연결 관계가 어떻게 처리되는가
  - 수수료율에 0% 또는 100% 경계값 입력 시 처리
  - 운영 대행 수수료의 "대상 파트너 선택" 드롭다운이 직관적으로 작동하는가
  - "변경 취소" 버튼이 입력값을 실제로 이전 상태로 되돌리는가

---

### T4. 파트너 할당 기준 — 광고 단위 ID 관리

- **목표**: 파트너별로 정산에 포함할 광고 단위 ID를 등록하고, 검색·수정·삭제가 잘 동작하는지 확인한다
- **시작 지점**: 상단 내비게이션 → 파트너 할당 기준
- **성공 기준**:
  - 파트너 목록 타일에서 원하는 파트너를 선택해 광고 단위 관리 화면으로 진입된다
  - 광고 단위 ID를 일괄 붙여넣기(여러 ID를 개행·쉼표 구분)로 추가할 수 있다
  - 중복 ID는 자동 제외되고 실제 추가된 건수를 확인할 수 있다
  - 광고 단위 ID 검색이 정상 동작한다
  - 저장 후 타일의 개수 카운트가 업데이트된다
- **관찰 포인트**:
  - 파트너 정산 비율에 파트너가 등록되지 않은 경우 안내 메시지가 나타나는가
  - 페이지네이션이 있는 경우 페이지 이동이 정상 동작하는가
  - 선택 삭제 기능(체크박스 → 삭제)이 의도대로 작동하는가
  - "목록으로" 뒤로가기가 정상 작동하는가

---

### T5. 월별 서빙피 단가 설정 및 마감

- **목표**: 이번 달 광고게재 단가 구간별 금액과 차감분을 입력해 평균 서빙피 단가를 확인하고 마감한다
- **시작 지점**: 상단 내비게이션 → 월별 서빙피 단가
- **성공 기준**:
  - 단가 구간(광고게재 행)을 1개 이상 추가하고 단가($)·impressions 범위·금액($)을 입력할 수 있다
  - 차감분을 추가해 합계에 반영되는지 확인된다
  - 합계 금액이 0이 아닌 경우 오른쪽 패널에 "평균 서빙피 단가"가 자동 계산되어 표시된다
  - 저장 후 확인 피드백이 나타난다
  - 마감 토글 활성화 후 필드가 잠기고 "마감" 배지가 표시된다
- **관찰 포인트**:
  - 금액 합계가 0일 때 평균 단가 계산 불가 안내가 명확한가
  - 단가 구간 삭제 후 비중(%) 재계산이 즉시 반영되는가
  - "이전 달 기준으로 되돌리기" 링크의 동작이 직관적인가

---

### T6. 월별 정산 기초 자료 업로드 및 파트너 할당

- **목표**: 광고수익총금액 CSV와 서빙피계산 인보이스확인 CSV를 업로드하고, 미할당 광고 단위를 파트너에 배정한 뒤 마감한다
- **시작 지점**: 상단 내비게이션 → 월별 정산 기초 자료
- **성공 기준**:
  - "월별 정산 기초 자료 업로드" 모달을 열어 두 가지 CSV 파일을 각각 업로드할 수 있다
  - 업로드 후 "N건 로드됨" 메시지가 표시된다
  - 광고수익총금액 탭에서 미할당 광고 단위에 파트너를 배정(할당)할 수 있다
  - 파트너별 수익비율 합이 상단 요약에 표시된다
  - 서빙피 자료 탭에서도 동일하게 파트너 할당 및 요약 확인이 가능하다
  - 엑셀로 내보내기 버튼 클릭 시 파일이 다운로드된다
  - 마감 토글 활성화 후 업로드 및 편집이 불가해진다
- **관찰 포인트**:
  - 마감된 년월에 업로드 시도 시 경고 메시지가 나타나는가
  - 미할당 건수 경고(노란색)가 명확하게 표시되는가
  - 파트너 변경(이미 할당된 광고 단위의 파트너 재배정) 시 모달이 올바르게 동작하는가
  - 검색 필터와 파트너 필터가 함께 동작하는가

---

### T7. 실정산금액 및 기준환율 입력

- **목표**: 인보이스 입금·송금 금액($)과 입금·비용 금액(원)을 입력해 정산 기준환율을 확인하고 마감한다
- **시작 지점**: 상단 내비게이션 → 실정산금액 및 기준환율
- **성공 기준**:
  - 매출(금액) 및 서빙피(비용) 행의 인보이스 금액($)과 입금 금액(원)을 입력하면 환율이 자동 계산된다
  - 오른쪽 요약 카드에 "정산 기준환율"이 표시된다 (소수점 이하 절삭)
  - 서빙피(비용) 원화 = 서빙피 인보이스($) × 기준환율이 자동 계산되어 표시된다
  - 저장 후 성공 피드백이 나타난다
  - 마감 후 모든 입력 필드가 잠긴다
- **관찰 포인트**:
  - 인보이스 금액을 0으로 입력했을 때 나누기 오류(divide by zero) 처리가 적절한가
  - "변경 취소" 버튼이 저장된 값으로 올바르게 복원하는가
  - 입력·계산값 범례(legend)가 명확히 구분되는가

---

### T8. 월별 정산 실행 및 상세 결과 확인

- **목표**: 이전 단계에서 마감한 기초 데이터를 기반으로 특정 년월의 정산을 실행하고, 3개 탭(광고 매출 수수료 정산·운영대행 수수료 정산·최종 정산액 확인)에서 계산 결과를 검증한다
- **시작 지점**: 상단 내비게이션 → 월별 정산
- **성공 기준**:
  - "새로운 년월 정산하기"로 년월을 추가하고 목록에 행이 생성된다
  - 각 기초 데이터(파트너 정산비율·서빙피 단가·기초자료·기준환율)의 마감 상태가 배지로 표시된다
  - "정산하기" 실행 후 정산 상태가 "완료"로 바뀐다
  - 상세보기 진입 후 "광고 매출 수수료 정산" 탭에서 파트너별 입금금액 배분액·서빙피 배분액·수수료·최종 정산금액·시냅스엠 수익이 표시된다
  - 합계 행이 있고 입금금액(원) 합계와 일치(또는 허용 오차 내)한다
  - "운영대행 수수료 정산" 탭에서 운영 대행 수수료가 설정된 경우 파트너별 수수료액이 표시된다
  - "최종 정산액 및 시냅스엠 수익 확인" 탭에서 매출·수수료·서빙피·시냅스엠 수익 합계가 정리되어 나온다
  - "다시 정산하기"로 재계산이 가능하다
- **관찰 포인트**:
  - 기초 데이터 일부가 마감되지 않은 상태에서 정산 가능한지, 그 경우 경고가 표시되는가
  - 미할당 광고 단위가 있을 때 경고 메시지가 결과 해석에 도움이 되는가
  - 툴팁(i 아이콘)의 설명이 실제 계산 공식과 일치하는가

---

### T9. 정산 마감 및 월별 리포트 확인

- **목표**: 완료된 정산을 마감하고, 월별 리포트에서 KPI 요약·파트너별 정산 요약·시냅스엠 수익 구성을 확인한다
- **시작 지점**: 월별 정산 목록 또는 상세보기
- **성공 기준**:
  - "정산 마감" 실행 후 상태가 "마감"으로 변경되고 "다시 정산하기"가 비활성화된다
  - "월리포트" 버튼이 활성화되고 클릭 시 월별 리포트 화면으로 이동된다
  - 리포트에서 매출(입금금액)·구글 서빙피·파트너 지급 합계·시냅스엠 수익 KPI 카드가 표시된다
  - 파트너별 정산 요약 표에서 각 파트너의 입금금액 배분액·서빙피 배분액·최종 정산 금액·비중이 확인된다
  - "핵심 지표 비교" 바 차트와 "시냅스엠 수익 구성" 플로우 차트가 정상 렌더링된다
  - "인쇄 / PDF" 버튼 클릭 시 인쇄 다이얼로그가 열린다
- **관찰 포인트**:
  - 마감 해제 후 다시 정산·마감 사이클이 반복 가능한가
  - 리포트 인쇄 시 "report-no-print" 요소(버튼, 경고 등)가 숨겨지는가
  - 리포트가 없는 상태에서 월별 리포트 메뉴 진입 시 빈 상태 안내 문구가 명확한가

---

### T10. 로그아웃 및 세션 보호

- **목표**: 로그아웃 후 시스템에서 안전하게 빠져나오고, 브라우저 뒤로가기로 재진입이 차단되는지 확인한다
- **시작 지점**: 로그인된 상태의 임의 메뉴
- **성공 기준**:
  - 로그아웃 실행 시 로그인 화면으로 이동된다
  - 로그아웃 후 뒤로가기 또는 URL 직접 접근 시 로그인 화면이 다시 표시된다 (세션 보호)
- **관찰 포인트**:
  - 로그아웃 버튼의 위치와 레이블이 직관적인가
  - 모바일 뷰에서 로그아웃 버튼에 접근이 가능한가 (햄버거 메뉴 내)
