QA 에이전트팀 · 시작하기

전문 지식 없이도 이 순서대로만 하면 됩니다. 5~10분이면 끝나요.

이 프로그램은 내 컴퓨터에서 도는 QA 도구입니다. 딱 3가지만 하면 시작합니다 — ① 프로그램 실행기(Node.js) 설치 ② 설치.bat 더블클릭 ③ 서버 시작.
나머지(비밀번호·설치·브라우저 준비 등)는 설치 프로그램이 자동으로 처리합니다.

1 Node.js 설치하기 (최초 1회)

이 프로그램을 돌리는 엔진입니다. 아래 버튼을 눌러 LTS 버전을 받아 설치하세요. 설치 중 선택지는 모두 기본값(다음)으로 넘어가면 됩니다.

Node.js 내려받기 →

이미 설치돼 있어도 버전 24 이상이어야 합니다. 낮으면 설치 프로그램이 알려주고 멈춥니다.

2 설치.bat 더블클릭 (최초 1회, 5~10분)

압축을 푼 폴더의 맨 위에 있는 설치.bat 파일을 더블클릭하세요. 검은 창이 뜨면서 필요한 것들을 순서대로 자동 설치·점검합니다.

처음 실행하면 두 가지를 물어봅니다:
  • 관리자 비밀번호 — 나중에 로그인할 때 쓸 비밀번호를 정하세요. (그냥 엔터를 치면 자동으로 만들어 화면에 보여줍니다 → 꼭 적어두세요)
  • API 키 — 있으면 붙여넣고, 없으면 그냥 엔터. (4단계에서 대신 로그인해도 됩니다)

마지막에 점검 결과표가 나옵니다. FAIL 이 없으면 준비 완료입니다. FAIL 이 있으면 그 줄의 “→” 안내대로 처리하고 다시 더블클릭하세요(여러 번 실행해도 안전합니다).

파일 이름이 ?��.bat 처럼 깨져 보이면 압축을 푼 도구가 한글을 잃은 것입니다. 그럴 때는 그 폴더에서 명령창을 열고 node install/install.mjs 를 입력하세요. (같은 동작)

3 서버 시작 · 브라우저 접속

webapp 폴더의 QA서버-시작.bat 을 더블클릭하세요. 잠시 뒤 브라우저가 http://localhost:5510 으로 자동으로 열립니다. (안 열리면 직접 주소창에 입력)

로그인:

  • 아이디: admin
  • 비밀번호: 2단계에서 정한(또는 자동 생성된) 관리자 비밀번호

이후에는 이 파일만 더블클릭하면 됩니다. 서버가 이미 켜져 있으면 브라우저만 열립니다.

4 Claude 인증 (새 QA를 '실행'하려면 필요)

설치가 끝났다고 QA 실행까지 되는 것은 아닙니다. 실제로 테스트를 돌리려면 Claude 사용 권한이 따로 필요합니다.

둘 중 하나만 하세요:

  • 구독 로그인 — 명령창에 claude login 한 번. (키 불필요)
    단, 이 명령은 Claude Code가 설치돼 있어야 씁니다. 없으면 먼저 npm i -g @anthropic-ai/claude-code 를 실행하세요.
  • 또는 — platform.claude.com에서 API 키를 발급받아 2단계에서 붙여넣기(또는 webapp\.env 의 ANTHROPIC_API_KEY 에 입력).
결과를 '보기만' 할 거라면 이 단계는 건너뛰어도 됩니다. 로그인·프로젝트 조회·상태/메모 편집은 인증 없이도 됩니다.

5 끝! 그리고 알아둘 것

이제 프로젝트를 등록하고 “시나리오·실행” 탭에서 QA를 돌릴 수 있습니다.
  • 인터넷이 필요합니다. 설치할 때(프로그램 내려받기)와 QA를 돌릴 때(Claude 접속) 모두.
  • 화면 디자인이 인터넷의 글꼴·스타일을 쓰기 때문에, 회사 방화벽이 막으면 모양만 투박해질 수 있습니다(기능은 정상).
  • 실제 브라우저로 테스트하려면 Claude Code에서 이 폴더를 열고 MCP 서버 사용을 “승인”해야 합니다. 승인하지 않으면 흉내내기(시뮬레이션) 모드로 돌아갑니다.

잘 안 될 때 — 먼저 자기진단

폴더에서 명령창을 열고 node install/doctor.mjs 를 입력하면 무엇이 문제인지 표로 알려줍니다(아무것도 바꾸지 않습니다). 고치려면 node install/install.mjs — 여러 번 실행해도 안전합니다.
  • 검은 창이 “Node.js 없음”이라고 함 → 1단계 설치 후 다시 더블클릭.
  • “Node 버전이 낮다”며 멈춤 → 24 이상이 필요합니다. 22·23은 안 됩니다(설치는 되는 척하고 서버만 죽습니다).
  • 서버가 바로 꺼짐 / [auth] 오류 → 설정값이 비어 있는 경우입니다. 설치.bat을 다시 더블클릭하면 자동으로 복구합니다.
  • “QA 실행 실패” → 4단계 인증(로그인 또는 API 키)이 안 된 것입니다.
  • 포트가 이미 쓰인다고 함 → 명령창에서 node install/install.mjs --port=5511 (다른 번호로 바꿔줍니다).
  • 주소가 안 열림 → 검은 창이 켜져 있는 상태에서 http://localhost:5510 을 직접 입력.

더 자세한 설명 (선택)

수동 설치, 다른 운영체제(macOS·Linux — sh install.sh), 상시 가동·서버 배포, 기존 PC의 QA 결과 옮기기 등은 같은 폴더의 SETUP-NEW-PC.md 와 webapp/DEPLOY.md 에 있습니다. 이 패키지에 무엇이 들어 있고 무엇이 빠졌는지는 MANIFEST.txt 를 보세요.
