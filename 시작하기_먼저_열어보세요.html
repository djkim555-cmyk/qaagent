QA 에이전트팀 · 시작하기

전문 지식 없이도 이 순서대로만 하면 됩니다. 5~10분이면 끝나요.

이 프로그램은 내 컴퓨터에서 도는 QA 도구입니다. 딱 3가지만 준비하면 시작합니다 — ① 프로그램 실행기(Node.js) 설치 ② 시작 버튼 더블클릭 ③ Claude 로그인.
나머지(비밀번호·설치 등)는 자동으로 처리됩니다.

1 Node.js 설치하기 (최초 1회)

이 프로그램을 돌리는 엔진입니다. 아래 버튼을 눌러 LTS 버전을 받아 설치하세요. 설치 중 선택지는 모두 기본값(다음)으로 넘어가면 됩니다.

Node.js 내려받기 →

이미 설치돼 있다면 이 단계는 건너뛰어도 됩니다. (버전 24 이상 권장)

2 시작 버튼 더블클릭

webapp 폴더 안의 QA서버-시작.bat 파일을 더블클릭하세요. 검은 창이 뜨면서 자동으로 설치가 진행됩니다.

처음 실행하면 두 가지를 물어봅니다:
  • 관리자 비밀번호 — 나중에 로그인할 때 쓸 비밀번호를 정하세요. (그냥 엔터를 치면 자동으로 만들어 화면에 보여줍니다 → 꼭 적어두세요)
  • API 키 — 있으면 붙여넣고, 없으면 그냥 엔터. (3단계에서 대신 로그인합니다)

이후에는 같은 파일을 더블클릭할 때마다 바로 서버가 켜지고 브라우저가 열립니다.

3 Claude 인증 (새 QA를 '실행'하려면 필요)

QA 에이전트가 실제로 테스트를 돌리려면 Claude 사용 권한이 필요합니다. 둘 중 하나만 하세요:

  • 쉬운 방법 — 이 PC에 Claude Code가 있으면 명령창에 claude login 한 번. (구독 계정으로 로그인, 키 불필요)
  • 또는 — platform.claude.com에서 API 키(sk-ant-...)를 발급받아 2단계에서 붙여넣기.
결과를 '보기만' 할 거라면 이 단계는 건너뛰어도 됩니다. 로그인·프로젝트 조회·상태/메모 편집은 인증 없이도 됩니다.

4 브라우저에서 접속·로그인

잠시 뒤 브라우저가 http://localhost:5510 으로 자동으로 열립니다. (안 열리면 직접 주소창에 입력)

로그인:

  • 아이디: admin
  • 비밀번호: 2단계에서 정한(또는 자동 생성된) 관리자 비밀번호
끝! 이제 프로젝트를 등록하고 “시나리오·실행” 탭에서 QA를 돌릴 수 있습니다.

잘 안 될 때

  • 검은 창이 “Node.js 없음”이라고 함 → 1단계 설치 후 다시 더블클릭.
  • 서버가 바로 꺼짐 / [auth] 오류 → 드문 경우입니다. webapp\.env 파일을 지우고 2단계부터 다시 하세요(설정이 새로 만들어집니다).
  • “QA 실행 실패” → 3단계 인증(로그인 또는 API 키)이 안 된 것입니다.
  • 주소가 안 열림 → 검은 창이 켜져 있는 상태에서 http://localhost:5510 을 직접 입력.

더 자세한 설명 (선택)

수동 설치, 다른 운영체제(macOS·Linux), 상시 가동·서버 배포, 기존 데이터 옮기기 등은 같은 폴더의 SETUP-NEW-PC.md 와 webapp/DEPLOY.md 에 있습니다.
